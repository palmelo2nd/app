# ナレッジ（note）

手順・コマンド・社内ルール・連絡先・学習メモなどを、ノート1枚＝1つのMarkdownファイルで持つナレッジアプリ。iPhoneで調べて見るのが主な使い方（2026-11-06作成）。

## できること（v1）
- 一覧：更新日の新しい順。分類（すべて／仕事／自分）で絞り込み
- 検索：題名・タグ・本文を、入力するたびに絞り込む（空白区切りでAND。カタカナ／ひらがな・全角／半角は同一視）
- 表示：Markdown（見出し・箇条書き・表・コードブロックなど）。コードブロックには「コピー」ボタン
- 編集・新規作成：題名・分類・タグ・本文。書きかけは端末に下書きとして残る
- 圏外でも閲覧・検索・編集ができる。圏外で保存したものは「未送信」として残り、次の「読込」か「保存」で送る
- 他の端末で同じノートが変わっていたときは上書きせず、どちらの版を残すかを選ぶ

## データ
- `app_data/note/<ID>_<題名>.md`（先頭に1行のJSONで属性、その下が本文）。詳しくは[CLAUDE.md](CLAUDE.md)
