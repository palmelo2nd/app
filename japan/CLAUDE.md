# japan（日本地図アプリ）の決まり

共通ルールは `app/CLAUDE.md` と `app/DESIGN.md`。ここには japan だけの決まりを書く。worldの作り（`world/CLAUDE.md`）を流用しているが、コードは複製して japan に持つ（部品はアプリごとに持つ、2026-11-24）。

- **公開リポジトリに置かないもの**：APIキー・トークンなどの端末ごとの設定（localStorage に `japan-` で始まるキーで置く）、再配布できないデータ、段階Bの個人のメモ（場所のメモは非公開のデータリポジトリに置く。段階Bで決める）。**Why:** `app` は public で GitHub Pages から誰でも読めるため。
- **キャッシュ名**：Cache Storage・localStorage のキーは `japan-` で始める。「キャッシュ更新」で消すのも `japan-` で始まるものだけ（`app/CLAUDE.md` 2章）。
- **地図ライブラリ**：MapLibre GL JS 6（worldと同じ版を固定で書く）。日本語の文字は端末の字（`localIdeographFontFamily`）。表示は平面だけ（地球儀なし。labで決定）。
- **データは `tools/build_data.py` で作る**（手で `data/` を直さない）。県の表（ふりがな・英語・地方・県庁所在地、政令指定都市の県庁のある区 `CAPITAL_WARD`）は `tools/prefs_table.py`。
  - 島を落とすのは県ごとにまとめた後（`-filter-islands`）。まとめる前に面積で落とすと、内陸の小さな飛び地が穴になる
  - 竹島・沖ノ鳥島・南鳥島・尖閣諸島は `KEEP_BOXES` で残し、簡略化しない（mapshaper の `-simplify keep-shapes` や `-clean` で消えたため）。データを作り直したら、この4つと北方領土（択捉・国後・色丹・歯舞）が `borders.json` に入っているかを確かめる
  - 出典：画面に「国土数値情報（行政区域データ）をもとに作成（加工）」と出す（国土数値情報の利用規約。国が作ったように見せない）
- **県庁所在地の印**は、その市（政令指定都市は県庁のある区、東京都は新宿区）の区域の代表点で、県庁の建物の位置ではない（国土地理院の県庁の座標の表が読めなかったため、2026-11-25）。
- **データのキャッシュバスティング**：`data/` は `?v=`（`js/app.js` の `DATA_VERSION`＝自分の `?v=`）で読む。データを作り直したら `index.html` の `?v=` を上げる。
