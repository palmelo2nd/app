# Japan（日本地図）

日本地図で、都道府県と、行きたいところのメモなど場所に属する情報を整理するアプリ（個人用、メニューは index_my だけ）。地図は MapLibre GL JS（平面・背景地図なしが基本）。worldの作りを流用した別のアプリ。

## 今の状態：段階A「都道府県を知る」（2026-11-25、v1）
- **地図**：都道府県を8地方（北海道・東北・関東・中部・近畿・中国・四国・九州沖縄）で色分けして表示。「表示」で背景なし・地図（OpenFreeMap、拡大して見たいとき）を切り替える
- **県を選ぶ**：地図の県を押すか、一覧から選ぶ。県名（漢字・ふりがな・英語）・地方・県庁所在地が出て、地図の県庁所在地に赤い印が付く。一覧から選ぶとその県へ寄せる
- **地方ボタン**（地図の上）：全国＋8地方。その地方へ寄せ、一覧もその地方に絞る
- **一覧・検索**：地方ごとの見出しで47件。県名・県庁所在地を漢字・ひらがな（カタカナでも可）・英語で探す
- 北方領土・竹島は日本の見解に合わせて北海道・島根県に含む（元データの国土数値情報に入っている）
- 出典の表示は右下の「i」（最初は閉じている）と画面の一番下

## データ（`data/`）
- `borders.json`：県の面（`prefs`、属性は `code`＝JISの都道府県コード）と、県と県が接する線（`lines`）の TopoJSON。約410KB
- `prefs.json`：県ごとの情報（`ja`・`kana`・`en`・`region`・`cap`（県庁所在地の名前と印の位置）・`lx`/`ly`（県名の位置）・`bbox`（寄せる先））と、地方ごとの寄せる先（`regions`）。約12KB
- 作り方：`tools/build_data.py`（国土数値情報「行政区域」N03 の全国版を、県ごとにまとめ、0.5km²未満の島を落とし、mapshaper で簡略化。竹島・沖ノ鳥島・南鳥島・尖閣諸島は落とさない）。県の表は `tools/prefs_table.py`
  ```
  python japan/tools/build_data.py <N03-YYYYMMDD.shp> [簡略化の割合 既定0.7%] [落とす島の面積km² 既定0.5]
  ```
  元データ（約800MBのzip）は https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-2026.html から落とし、リポジトリには置かない
- 出典：「国土数値情報（行政区域データ）」（国土交通省、CC BY 4.0）をもとに作成。画面に出典と加工したことを出す（国土数値情報の利用規約）
