# World（世界地図）

世界地図で、国・飛行機・紛争・物流などを見るアプリ（個人用、メニューは index_my だけ）。地図は MapLibre GL JS。

## 今の状態：段階0（試作、2026-11-10）
背景地図・日本語の文字・飛行機の描画の重さを試すページ。

- 背景：「タイルなし」（Natural Earth 110m の国の面と境界、world-atlas）／「OpenFreeMap」（liberty の地図、地名は日本語優先）
- 表示：地球儀／平面
- 日本語の文字：「端末の字」（漢字・かなは端末のフォントで描く。MapLibre の `localIdeographFontFamily`）／「サーバーの字」（全部 OpenFreeMap の字の配信を使う）。下に表示までの時間と、字の配信の件数が出る
- 飛行機：テスト用の乱数（1,000／5,000／10,000機）、adsb.lol・adsb.fi・OpenSky への直接の取得、中継URL。描く時間と件数が出る。印を押すと便名と高度が出る
  - 2026-11-10の確認では、3つの取得元とも、ブラウザからの直接の取得はCORSで断られる（中継が要る）
  - 中継URLはこの端末の localStorage（`world-relay-url`）にだけ保存する
