# 漢字学習アプリ

小学校配当漢字（学年別）を、読みクイズ・意味熟語クイズ・フラッシュカードで学習できるWebアプリ。HTML+CSS+JavaScript（バニラJS、ESモジュール）で構築し、[Second Brain](../brain/README.md)と同様にGitHub Pages想定・GitHubリポジトリへのデータ保存に対応する。

iOS/Android向けアプリとしてのストア販売を見据え、開発を以下の部門フォルダに分けて記録している（実装コード自体はこのリポジトリ直下＝「開発」部門にあたる）。

## 1. 対象漢字・データ構成

小学校で習う学年別配当漢字（1年〜6年、1006字）を収録。各漢字は「学年」「画数」「音読み」「訓読み」「意味」「熟語（2件程度）」を持つ。

漢字そのもののデータ（読み・意味・熟語）はユーザーごとに変わらないため、`data/kanjiMaster.json`としてアプリ本体（コードリポジトリ）に同梱している。学習の進捗（出題回数・正解回数など）だけを、Second Brainと同じデータリポジトリ（`palmelo2nd/app_data`の`kanzi/data.md`）にGitHub API経由で保存する。この分離の理由は[CLAUDE.md](./CLAUDE.md)の「2. データの分離方針」を参照。

現時点では、`kanjiMaster.json`側の日本語の「意味」は5,514字中5,474字（99.3%）まで到達（Wiktionaryでの直接取得74%＋英語グロスからの機械翻訳分。詳細は`CLAUDE.md`）。`jukugo.json`（熟語）は学年1〜6（小学校配当漢字）3,080件、4級〜2級（中学〜高校レベル）2,370件に加え、準1級・1級2,091件を新規収録し、合計7,541件（[10章](#10-既知の制約今後の拡張候補)参照）。

## 2. 級の選択とクイズタブ

画面上部の「対象級」プルダウンで、漢検10級〜1級のいずれか1つを選ぶ（2026-08-31、学年ベースの選択から刷新。`kanjiMaster.json`の「級」フィールドを直接見るため、学年からの近似では拾えなかった級のズレも正確に反映される）。選択はホーム・クイズ・意味熟語クイズ・フラッシュカード・成績のすべてのタブに共通で適用され、切り替えると出題中の問題やカードは作り直される。プルダウンの末尾には開発者専用の「開発」も選択肢として含まれる（[CLAUDE.md](./CLAUDE.md)「6. 開発タブ」参照）。

ナビゲーションの「クイズ」タブを開くと、選択中の級で実際に出題される漢検の公式ジャンル（漢字の読み・書取・部首部首名・筆順画数・送り仮名・対義語類義語・同音同訓異字・熟語の構成・誤字訂正・故事諺など、級によって異なる。出典は[00_市場調査/出題範囲（公式基準）.md](./00_市場調査/出題範囲（公式基準）.md)）に応じたサブタブが並ぶ。現状クイズが実装済みなのは「漢字の読み」「漢字の書取」「筆順・画数」（筆順のみ）の3ジャンルで、他のジャンルは「準備中」と表示される（実装は今後1ジャンルずつ追加予定）。

## 3. 読みクイズ（漢字の読み）

「クイズ」タブの「漢字の読み」サブタブの中身。熟語を使った短い例文を表示し、文中でハイライトされた熟語の読みを4択で答える（例：「きょうそうで<u>一番</u>になった。」→「いちばん／いちにち／いちまい／いちど」）。単漢字だけを見せる出題ではなく、実際に文章の中で使われる形で読みを問うことで、より実践的な出題にしている。出題は、進捗が悪い（正答率が低い）漢字・未学習の漢字ほど選ばれやすい重み付き抽選（`js/modules/progress.js`の`calcWeight`）で行う。回答すると正誤と正解を表示し、「次の問題」で次へ進む。

例文データは学年1〜6（小学校配当漢字）・4級〜2級（中学〜高校レベル）・準1級〜1級（大学・専門レベル）を含む全7,541件で完備済み（[10章](#10-既知の制約今後の拡張候補)参照）。

## 4. 書取クイズ（漢字の書取）

「クイズ」タブの「漢字の書取」サブタブの中身（2026-08-31実装）。読みクイズの逆で、例文中の対象語を読み（ひらがな）に置き換えて表示し、正しい漢字表記を4択で答える（例：「けいさつかんに<u>みち</u>をたずねる。」→「道／未知／満ち／御地」）。母集団の抽出・重み付き抽選・進捗反映は読みクイズ（3章）と完全に同じ仕組みを流用しており（`js/modules/quiz.js`の`buildWritingQuiz`）、対象語以外の高度な漢字へのふりがな表示も読みクイズと同様に付く。

## 5. 筆順クイズ（筆順・画数）

「クイズ」タブの「筆順・画数」サブタブの中身（2026-08-31実装、現状は筆順のみ）。漢字を1画だけ太字（青色）で強調表示し、それが何画目に書く画かを4択で答える。漢字マスタとは別の`data/strokeOrder.json`（KanjiVG由来の筆順データ、約15MB）を使うため、初めてこのタブを開いたときだけ読み込みに少し時間がかかる（開発タブの筆順レビューと同じ遅延読み込みを共用）。表示はHanziWriterのアニメーション機能ではなく、`strokes`（塗りつぶし輪郭パス）を直接使った自前の静止画SVG描画（詳細は[CLAUDE.md](./CLAUDE.md)「6. 開発タブ」参照）。

## 6. 意味・熟語クイズ

漢字の意味を4択で当てる問題と、熟語の空欄（例：「＿番」）に入る漢字を4択で当てる問題を、ランダムに出し分ける。意味・熟語データがある漢字のみが対象。対象漢字が4字未満の級を選ぶと、その旨のメッセージを表示する。

## 7. フラッシュカード

対象級から重み付き抽選で最大20枚のカードを作り、1枚ずつ表示する。カードをタップ／クリックすると裏面（音読み・訓読み・意味）が出て、「もう一度」「覚えた」で自己採点する（この自己採点も進捗に反映される）。最後まで進むと「最初からやり直す」で新しいセットを作れる。

## 8. 成績

対象級内の学習済み字数・平均正答率と、正答率が低い（かつ一定回数以上出題済みの）「苦手な漢字」を最大20件、正答率の低い順に表示する。

## 9. 設定・データの保存

GitHub Personal Access Token（Contents権限、`palmelo2nd/app_data`への読み書きが必要）を入力し、「読み込み」で進捗をGitHubから取得、「保存」でLocalStorageとGitHubの両方に反映する。

- クイズ・フラッシュカードで1問答えるたびに、進捗はLocalStorageへ即座に保存される（オフラインでも進捗は失われない）。GitHubへの反映は「保存」ボタンを押したときのみ行われる。
- 保存時にGitHub側が別端末等で更新されていた場合（409エラー）は、その旨を表示するので「読み込み」で最新化してから再保存する。

## 10. 既知の制約・今後の拡張候補

- `kanjiMaster.json`は漢検10級〜1級の全5,514字ぶん「級」「画数」「音読み」「訓読み」「部首」「部首名」が入っている（2026-08-30完成。出典は[01_技術調査/外部データソース調査.md](./01_技術調査/外部データソース調査.md)参照）。「意味」もウィクショナリー日本語版から機械的に74%（4,063字）まで補完済み。残り1,451字（1級・準1級中心）は[01_技術調査/意味データ_未解決文字リスト.md](./01_技術調査/意味データ_未解決文字リスト.md)に一覧化。
- `jukugo.json`は学年1〜6（小学校配当漢字）3,080件、4級〜2級（中学〜高校レベル）2,370件、準1級・1級2,091件の合計7,541件を機械取得で収録済み（英語グロスからの機械翻訳分は`意味_機械翻訳`フィールドで区別）。**`例文`も全7,541件で完備済み**で、10級〜1級の全ての級で読みクイズが出題できる。生成した例文・対象級は`例文_確認状態`／`対象級_確認状態`が`未確認`のままで、アプリ内の「開発」（開発者専用、ヘッダーの対象級プルダウンの選択肢の1つ）でレビュー・編集し、GitHubへ保存できる（[CLAUDE.md](./CLAUDE.md)「6. 開発タブ」参照）。準1級・1級の候補語未カバー825字（常用漢字表・JMdictいずれにも収録が無い極めて希少な字）への対応は今後の課題。追加・修正する際は`code/kanzi/data/kanjiMaster.json`・`data/jukugo.json`を辞書等で確認しながら直接編集する（詳細は[CLAUDE.md](./CLAUDE.md)）。
- 2020年度改訂で追加された都道府県名関連の20字（茨・栃・埼・岡・阪など）は`kanjiMaster.json`に**エントリ・音読み・訓読み・画数まで追加済み**（2026-08-30、[davidluzgouveia/kanji-data](https://github.com/davidluzgouveia/kanji-data)の常用漢字全体データより補完）。意味は他学年同様まだ空。
- **例文で、対象語以外に対象級より高度な漢字が使われている箇所には、読みクイズ表示時にふりがな（ルビ）が付く**（2026-08-30、10級〜5級の全レベルに対応済み、合計917件）。あわせて各級の`対象級`を`kanjiMaster.json`の実際の級（構成漢字の最大値）に基づいて再計算し、10級〜5級で合計1,323件を正しい上位級へ再分類した（10級267件・9級以降1,056件）。4級以上はもともと対象級が構成漢字の最大級から機械的に算出されていたため、この種の不一致は生じていない。
- **「クイズ」タブは対象級に応じた出題形式サブタブを持つが、実装済みなのは「漢字の読み」「漢字の書取」「筆順・画数」（筆順のみ）の3ジャンル**（2〜5章参照）。「部首・部首名」「送り仮名」「対義語・類義語」「同音・同訓異字」「熟語の構成」「誤字訂正」「故事・諺」・「筆順・画数」の画数側（何画あるかを問う出題）は準備中プレースホルダーの状態で、今後1ジャンルずつ実装予定。送り仮名例（全級1,188字・1,674例）はデータ投入済みのため実装しやすい候補（2026-08-31時点）。
