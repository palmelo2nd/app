# デザイン

アプリのUI/UX・ブランドイメージ・ストア掲載素材を検討・記録するフォルダ。UX（画面遷移・機能面）とビジュアル（配色・アイコン等）は性質が違うため、ファイルを分けて記録する（[00_市場調査](../00_市場調査/README.md)と同じ「1部門＝1フォルダ＋トピック別ファイル」の運用）。

## 中身

| ファイル | 役割 |
|---|---|
| [UX設計.md](./UX設計.md) | 画面遷移・情報設計。級選択・段階的アンロックのUI、既存画面の棚卸し |
| [ビジュアルデザイン.md](./ビジュアルデザイン.md) | 配色・フォント・アイコン等のブランド面（未着手） |

## 記録すること

- ワイヤーフレーム・画面遷移案
- アイコン・配色・フォントなどのブランドガイド
- 既存Web版（`css/style.css`）からの見直し案（スマホアプリとしての最適化）
- ストア掲載用スクリーンショット・プロモーション素材の下案

## ステータス
