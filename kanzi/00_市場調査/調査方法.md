# 調査方法

競合調査で使う情報源と確認内容を先に定義しておく。競合ごとの記録には、どの方法で得た情報かを明記する（[書類作成ルール](../99_企画/書類作成ルール.md)に準拠）。

## 使用する情報源

| 方法 | 確認内容 | 備考 |
|---|---|---|
| App Store（iOS）掲載ページ・レビュー | 価格、課金形態、評価点数、レビュー件数、レビュー本文の傾向（高評価・低評価双方） | 実機無しでもWeb版の掲載ページから確認可能 |
| Google Play（Android）掲載ページ・レビュー | 同上 | **注意**：Google Playの個別ページはページが長大でWebFetch等のツールが内容を取得しきれず切り詰められることがあった。その場合はWeb検索の要約や、同一アプリのApp Store側ページ（iOS/Android両対応アプリが多い）で代替確認するとよい |
| レビューサイト・比較記事（Web検索） | 「漢字学習アプリ おすすめ」等のまとめ記事、ブログでの使用感レポート | ストアレビュー（一次情報）を補完する二次情報として扱う |
| 漢検関連コミュニティ・SNS・Q&Aサイト | 漢検準1級・1級の学習者が実際に使っているツール・不満点 | ターゲット層（学びなおし・資格志向）に近い生の声を拾う狙い |
| 公式サイト・アップデート履歴 | 開発元、アップデート頻度、機能一覧 | 継続開発されているか（放置アプリでないか）の確認 |

## 実施手順（2026-08-29の調査で確立）

1. Web検索でアプリ名の候補・比較記事を洗い出す（キーワード例：「漢検アプリ おすすめ」「大人 漢字 学び直し アプリ」）。まずは検索上位の常連4〜5件で「市場のスタンダード」（価格帯・評価・強み弱みの相場観）を把握する
2. 候補ごとにApp Store／Google Playの個別掲載ページURLを特定する
3. **個別ページURLを直接開いて**価格・評価点数・レビュー件数・開発者名・説明文・レビュー内容を確認する（検索結果の要約だけでは評価点数やレビュー件数が不正確／欠落しがちなため、必ずページ本体を確認する）
4. 1〜3だけでは同じ顔ぶれのアプリしか出てこないため、**狙って手薄な領域を追加調査する**（例：ターゲット層に近い切り口（シニア向け等）、公式・準公式アプリ、対象級・ジャンルが異なるもの）
5. **App Store／Google Playのカテゴリ人気チャートを直接確認する**（例：`apps.apple.com/jp/charts/iphone/education-apps/6017`）。正確なDL数は非公開だが、チャート順位は市場規模感（メジャーな市場かニッチな市場か）を測る代理指標になる
6. 競合アプリの**レビュー本文を読み込み、価格・評価だけでなく「コンセプトを裏付ける／覆すユーザーの生の声」がないか探す**（例：「上位級も追加してほしい」等の要望はコンセプト検証の一次情報になる）

## 記録のルール

- 競合ごとに「情報源（上記のどれか）」「確認日（絶対日付）」を明記する
- レビューからの引用は要旨のみとし、ユーザー名など個人が特定される情報は含めない
- 一次情報（ストア公式データ：価格・評価点数・件数）と二次情報（レビュー内容の傾向、まとめ記事の評価）を区別して書く
