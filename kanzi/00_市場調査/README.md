## 示唆・考察

- **課金モデルはほぼ「基本無料＋広告削除の買い切り課金（¥300〜900）」に収束**している。サブスクモデルの競合は見当たらなかった → 00の価格モデル検討の出発点にできる
- **上位級（準1級・1級）特化アプリは評価4.5〜4.6と軒並み高評価**。レビュー件数は数百〜数千件規模で、低学年向けアプリ（十万件超）と比べ母数は小さいがロイヤルティの高いニッチ市場と言える
- **全アプリ共通の弱点は「広告の頻度・しつこさ」**。真剣に学びたい大人向けという今回のコンセプトは、ここを避ける（広告に頼らない／控えめにする）だけでも差別化になりうる
- **「意味を見ながら読みを覚える」「苦手問題の自動追跡・復習」は高評価の共通要因**。現行アプリの`progress.js`の重み付け出題・苦手漢字抽出はこの路線と合致している
- **小学校配当漢字〜漢検1級までを1本のアプリで一気通貫にカバーする競合は、今回の調査では見つからなかった**。各アプリは特定の級・レベル帯に特化している。「学びなおし世代が小学生レベルから1級まで同じアプリで学べる」という[コンセプト](./コンセプト.md)は、競合の中でも独自性がありそう
- ゲーミフィケーション（ログインボーナス等）を前面に出しているアプリは見当たらず、「真剣に学びたい人向けの実用ツール＋軽いモチベ機能」という方向性と市場の間に大きなギャップは無さそう
- ジャンル別の機能比較（[機能比較.md](./機能比較.md)）では、**上位級（準1級・1級）で読み・書き・対義語類義語・四字熟語・故事諺を一気通貫でカバーする競合は見当たらなかった**。多くは特定ジャンルまたは特定級に特化しており、「小学校配当漢字〜1級まで」かつ「主要ジャンルを網羅」を両立するアプリは市場に空白がある可能性が高い
- **「漢検クイズ 5〜10級対策」のレビューに「4、3、2、1級を追加課金でいいので増やしてください」という具体的な要望があった**。低学年〜上位級までを1本のアプリでカバーしてほしいという実需をユーザーの生の声（一次情報）で確認できた。今回のコンセプトを直接後押しする材料
- STUDYSWITCH社は「小学生版（10〜6級、¥1,200買い切り）」と「本体版（2〜6級、無料＋¥500）」を**別アプリとして分割販売**している。同一開発者ですら小学生〜上位級を1本のアプリに統合していない点は、一気通貫アプリの設計・UI上のハードル（対象範囲が広がるほど難易度切り替えの複雑さが増す等）を示唆している可能性があり、[01_技術調査](../01_技術調査/README.md)・[02_デザイン](../02_デザイン/README.md)で検討材料にする
- App Store教育カテゴリの人気チャート（無料上位25件）には漢字系アプリが1つも入らず、英語学習系アプリが独占していた。**漢字学習アプリはバズる市場ではなく地道なニッチ市場**であることが裏付けられた
- シニア向け「ボケ防止」訴求アプリは評価・レビュー数が伸び悩んでいた（3.3/5.0・3件など）。真剣な資格学習ツールという今回の方向性は、こうした軽いポジショニングの「脳トレ」系とは異なる層を狙えそう
- **日本漢字能力検定協会公式の「漢検スタート」が、今回調査した10アプリ中で最低評価（2.3/5.0）だった**。「級ごとに課金が必要で高額になりがち」「模試は無料だと1回のみ」「手書き反応が悪い」といった不満が中心。**公式＝安心という立場にありながらUX面で評価が低く、民間アプリに付け入る隙が大きい**ことを示す強い材料
- **1級専門アプリ「30日合格プログラム」は¥4,800という突出した価格でも評価3.8・著名人の活用実績あり**。上位級の専門性が高いコンテンツには、他アプリ（¥300〜1,200が相場）よりかなり高い価格でも払う意思のあるユーザーがいることが分かる → [価格・課金モデルの検討](#7-設定データの保存)で「上位級は高単価でも成立しうる」という仮説の裏付けになる
