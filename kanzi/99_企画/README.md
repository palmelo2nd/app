# 99_企画

`00`〜`06`（漢字アプリの各部門フォルダ）は今回のアプリ固有の実務記録。このフォルダはその一段上の階層で、**業務の進め方そのもの**を一般化・蓄積する場所。漢字アプリでの実践を通じて得た反省点・改善点をここに反映し、次に別のアプリを開発するときのロードマップ（雛形）として再利用することを目的とする。

「99」は番号の並び（00〜06…）に対して常に最後尾に来るようにする意図の欠番。部門フォルダが増えても（例：07, 08…）企画フォルダの位置づけは変わらない。

## 中身

| ファイル | 役割 |
|---|---|
| [部門構成テンプレート.md](./部門構成テンプレート.md) | 各部門（市場調査・技術調査・デザイン・開発・QA・リリース・運用）を一般化した定義。新しいアプリを始めるとき、このテーブルをコピーして`00`〜`06`フォルダ群を再構築する |
| [書類作成ルール.md](./書類作成ルール.md) | 各部門のREADME・記録文書をどう書くか（構成・見出し・ステータス表記などの型） |
| [振り返りログ.md](./振り返りログ.md) | 部門ごとに「やってみて分かったこと・改善したいこと」を都度追記するログ。ここに溜まった内容を、時々`部門構成テンプレート.md`や`書類作成ルール.md`側に反映（一般化）する |

## 運用の流れ

1. `00`〜`06`で実務を進める中で、やり方に気づき・反省・改善案が出たら、都度 [振り返りログ.md](./振り返りログ.md) に一行でも追記する（完璧にまとめようとせず、思いついた時点で書く）
2. ある程度たまったら、共通化できる知見を [部門構成テンプレート.md](./部門構成テンプレート.md) や [書類作成ルール.md](./書類作成ルール.md) に反映する
3. 次のアプリを始めるときは、このフォルダの内容を出発点にして部門フォルダ一式を作る

- [ ] 漢字アプリでの実務を通じた振り返りの蓄積（これから）
