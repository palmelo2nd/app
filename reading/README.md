# reading（読む・目指す・決まり・記録）

旧book（読書ビューア、2026-09-27作成）と旧dream（2026-10-12作成）を2026-11-17に1つにまとめたアプリ。表紙から4つの機能を選ぶ（上の切り替えでも移れる）。

| 機能 | 中身 | データ |
|---|---|---|
| book（読む） | 書籍・新聞・調査・講義ノート、雑学と学びの記録、学びの途中経過 | `app_data/reading/01_book` |
| dream（目指す） | 教養マップ・お金の目標と実績・習慣チャレンジ（月ごとの記録つき）・人生の目標・やりたいこと | `app_data/reading/02_dream` |
| rules（決まり） | 各スレッドのルール（CLAUDE.md）・スキル・作業役、myselfの案内、くらしの決まり | `app_data/reading/03_rules` |
| log（記録） | 作業ログ、取り組みの現在地（HUB・引き継ぎ・labの検討メモ）、出張と宿泊 | `app_data/reading/04_log` |

rules・log・学びの途中経過・習慣チャレンジの月ごとの記録は、毎朝の自動処理が元のファイルから作る写し（手では直さない）。

## bookでできること（旧book v33）
- 本棚：表紙・進捗つきのカード一覧。新聞（日経）は先頭に固定
- 本文：ページ送り、「完了」チェック、4色のマーカー（TIPS・要点・QAの各タブに一覧）、図版・Mermaidの図の表示
- 暗号化版：URLに`?src=book_data`を付けると、暗号化した本（`book_data`リポジトリ）を読む（移行中、brain #1520）
- 圏外で読む：本ごとに端末へ保存すると、電波が無くても本文・図版を読める

## 圏外で読むときの使い方
1. readingのURL（`…/app/reading/?m=book`）をSafariで開き、共有メニューから「ホーム画面に追加」して、以後はホーム画面から開く（ホーム画面に置かないと、iPhoneが保存データを消すことがある。ホーム画面版はトークンの入れ直しが要ることがある）
2. 電波のある所で本を開き、左の「端末に保存」を押す。容量を抑えたいときは「図版も含める」を外す。保存前に容量の目安が出る
3. 圏外では、保存した本だけが開ける。付けた既読・マーカーは「未送信」として端末に残る
4. 電波のある所で、本棚の下の「端末に保存した本」にある「すべて同期」を押すと、保存した本を最新にし、未送信を送る（他の端末の変更とは自動でまとめる）。本を開くだけでも、保存した本は最新に差し替わる
5. 要らなくなった本は、本を開いて「端末から削除」か、一覧の「削除」で消す（自動では消えない。GitHub上の本は消えない）

- 2026-11-17のreadingへの移行で、旧bookで端末に保存した本は引き継がれない。圏外で読む本は保存し直す
