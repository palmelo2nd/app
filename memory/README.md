# Memory

日中に「これ覚えておきたい」と思った語彙・数学記号・長文などを記録し、ライトナー式の間隔反復（Leitner system）でゲーム感覚に復習するための個人用フラッシュカードアプリです。

## できること

- **クイズ**：復習期限が来ているカードを、種別（語彙／数学記号／長文）タブごとに出題。表面を見て思い出せたら「答えを見る」→「覚えた／間違えた」を選ぶと、次の復習タイミングが自動で調整されます（正解が続くほど間隔が延び、間違えると振り出しに戻ります）
- **追加**：種別・表面（問題）・裏面（答え）・タグ・出典を入力して新しいカードを登録
- **一覧**：登録済みカードを種別ごとに一覧表示し、箱番号・正解/不正解回数・次回復習日を確認

## データの保存先

`palmelo2nd/app_data`リポジトリの`memory/data.md`に保存されます（コード本体は`palmelo2nd/app`リポジトリの`memory/`）。GitHub Personal Access Tokenをアプリ内の「設定」から入力すると、GitHub側と同期されます。
