# Diary（日記）

日記の閲覧と入力のアプリ。閲覧画面はbookと同じ形式（一覧 → サイドバー目次＋本文）。

## 画面
- 上部バー：brain/bookと同じ（読込・保存・トークン・キャッシュ更新・`vN`表示）
- **閲覧タブ**：年のカード一覧 → 年を開くとサイドバーに月の一覧、本文側は「サマリー」「日記」タブ
  - サマリー：年の日数・件数・文字数、月別表、**投稿者別**表
  - 日記：1日＝1ページで「← 前の日／次の日 →」（左右矢印キー可）。各投稿に**投稿者・投稿時刻・文字数**を表示
- **入力タブ**：日付（既定は今日）・投稿者・本文。文字数をリアルタイム表示（全体／改行・空白除く）。投稿者は確認表示付き、前回の名前を記憶、既存の投稿者名を候補表示。「投稿」でGitHubへ即時保存

## データ
- `palmelo2nd/app_data` の `diary/<西暦4桁>.md`（ローカル: `app_data/diary/`）。年ごとに1ファイル、Front Matter(JSON)の `diaryData` に1投稿＝1レコード
- レコード：`ID`・`日付`(YYYY/MM/DD)・`投稿者`・`本文`・`投稿日時`
- 年一覧は `diary/` ディレクトリの一覧(GitHub API)から検出
- 投稿競合(409)は取り直して1回だけ自動再試行
- 現状は投稿の追記のみ（編集・削除は未実装）

## キャッシュバスティング
`index.html`と`js/app.js`（import文含む）の`?v=N`を同じ値で更新する。
