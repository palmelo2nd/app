# Diary（日記）

3人ほどで書く、シンプルな日記アプリ。メニューは「日記」「設定」の2つ。

## 画面
- 上部バー：brain/bookと同じ（読込・保存・トークン・キャッシュ更新・`vN`表示）。各自の端末でトークンを入れて使う
- **設定**：自分の名前を設定（この端末に記憶）。記事・コメント・リアクションの名前に使う。名前が未設定なら起動時に設定を開く
- **日記**
  - 投稿者（カレンダーの上）：登録済みの人のボタンを押すと、その人として書く・コメントする・リアクションする（設定の名前と同じ値を切り替える）。新しい人は「＋新しい人（設定）」から設定で登録
  - 絞り込み：人のチップ（すべて／各投稿者）と、カレンダー（記事がある日に印。日付を押すとその日だけ、もう一度押すと解除）。両方を組み合わせ可
  - 記事を書く：日付（既定は今日）・本文（文字数表示）・写真1枚。本文の下書きは端末に自動保存
  - 一覧：新しい記事が上（日付→投稿日時の降順）。20件ずつ「もっと見る」
  - 各記事：投稿者・日付・本文・写真・投稿日時/更新日時・文字数・リアクション（👍❤️😂😮😢、誰が押したか表示）・コメント
  - 編集・削除：自分の記事とコメントだけ。編集すると「更新日時」が変わり、「投稿日時」は残る
  - 新着：選んでいる投稿者が前回開いた後に、他の人が書いた/直した記事・コメントに「NEW」
  - 返事：新着のコメントのうち、選んでいる投稿者の記事へのコメントと、その人が先にコメントした記事への後からのコメントを「NEW 返事」（オレンジ）で目立たせる。記事の枠もオレンジにして「返事 N件」を付け、投稿者欄に合計件数を出す

## 写真
- ブラウザ内で長い辺1280px・JPEG画質70%に縮めてから保存（だいたい150〜300KB）
- 保存先は `diary/photos/<記事ID>-<時刻>.jpg`。非公開リポジトリなので、表示時にトークン付きで取得する
- 写真を変える・外す・記事を消すと、古い写真ファイルも削除する

## データ
- `palmelo2nd/app_data` の `diary/<西暦4桁>.md`（ローカル: `app_data/diary/`）。年ごとに1ファイル、Front Matter(JSON)の `diaryData` に1記事＝1レコード
- 記事：`ID`・`日付`(YYYY/MM/DD)・`投稿者`・`本文`・`投稿日時`・`更新日時`・`写真`・`コメント`[{`ID`・`投稿者`・`本文`・`投稿日時`・`更新日時`}]・`リアクション`{絵文字: [名前]}
- v1の記事（更新日時・写真・コメント・リアクションなし）もそのまま読める
- 書き込みは毎回ファイルを取り直してから変更し、競合(409)は1回だけ自動再試行
- 年をまたいで日付を変えた記事は、年ファイル間で移動する

## 端末内（localStorage）
- `diary_my_name`（名前）、`diary_last_seen:<名前>`（新着判定用の前回時刻。投稿者ごと。v3までの`diary_last_seen`は初回だけ引き継ぐ）、`diary_draft`（下書き）、`diary_cache_*`（オフライン用キャッシュ）

## キャッシュバスティング
`index.html`と`js/app.js`（import文含む）の`?v=N`を同じ値で更新する。
