# 読書ビューア（book）

専門書（数学書など）を文字起こしした本文を、ページ送りで読み返すためのアプリ（2026-09-27作成）。本文はClaude（`book-reading`スキル）が登録し、アプリでは既読・マーカーだけを付ける。

## できること（v33）
- 本棚：表紙・進捗つきのカード一覧。新聞（日経）は先頭に固定
- 本文：ページ送り、「完了」チェック、4色のマーカー（TIPS・要点・QAの各タブに一覧）、図版・Mermaidの図の表示
- 暗号化版：URLに`?src=book_data`を付けると、暗号化した本（`book_data`リポジトリ）を読む（移行中、brain #1520）
- 圏外で読む：本ごとに端末へ保存すると、電波が無くても本文・図版を読める

## 圏外で読むときの使い方
1. bookのURLをSafariで開き、共有メニューから「ホーム画面に追加」して、以後はホーム画面から開く（ホーム画面に置かないと、iPhoneが保存データを消すことがある。ホーム画面版はトークンの入れ直しが要ることがある）
2. 電波のある所で本を開き、左の「端末に保存」を押す。容量を抑えたいときは「図版も含める」を外す。保存前に容量の目安が出る
3. 圏外では、保存した本だけが開ける。付けた既読・マーカーは「未送信」として端末に残る
4. 電波のある所で、本棚の下の「端末に保存した本」にある「すべて同期」を押すと、保存した本を最新にし、未送信を送る（他の端末の変更とは自動でまとめる）。本を開くだけでも、保存した本は最新に差し替わる
5. 要らなくなった本は、本を開いて「端末から削除」か、一覧の「削除」で消す（自動では消えない。GitHub上の本は消えない）

## データ
- `app_data/book/`（従来版）・`book_data`（暗号化版）。詳しくは[CLAUDE.md](CLAUDE.md)
