# 操作ノート（opnote）

スマホ・パソコンで教えた操作を、分類ごとに1項目＝1ページで残す、本のようなノート（2026-11-18作成、brain #1706）。
忘れたときに見返すまとめノート。save向け（index_saveと、スキルマップの「できることを増やす」の枝から開く）。

## 画面（上から）
- 上部バー：brain・diaryと同じ（読込・保存・トークン・キャッシュ更新・`vN`表示）。題の横に「スキルマップへ」
- 分類：「スマホ」「パソコン」（数は項目の数）
- 項目の一覧：番号つき。広い画面では左に常に出し、スマホでは閉じた欄（押すと開く）。メモのある項目には「メモN」
- 項目のページ：前・次、題、問いと答え（枠の中）、本文（手順など。キーは枠つき）、教えた日、メモ
- メモ：気づいたこと・つまずいたことを、たけ・たまが書き足す。消せるのは自分のメモだけ
- 設定・使い方（閉じた状態）：自分の名前（未設定ならスキルマップ・日記の名前）、使い方
- 前回開いていた分類・項目から始まる。URLに`?c=pc`などを付けるとその分類から

## データ
- 用途のデータリポジトリ（Indexが`app_data_repo`に書く。saveなら`palmelo2nd/save_data`）の`opnote/notes.md`
- `categoryData`：分類 `{ID, 名前, 並び順}`（`phone`＝スマホ、`pc`＝パソコン）
- `itemData`：項目 `{ID（i0001…）, 分類, 題, 問い, 答え, 本文（Markdown）, 並び順, 登録日, メモ:[{ID, 書いた人, 本文, 日時}]}`
  - 題・問い・答え・本文はbookスレッドが書く（アプリでは変えない）。問いと答えは、後で復習アプリで出題するために分けて持つ
- 項目を足す・直す：`python tools/opnote_add.py <notes.mdのパス> <分類ID> <題> <問い> <答え> <本文ファイル> [--id 項目ID] [--date YYYY/MM/DD]`（同じ分類・同じ題なら書き換え。メモは残る）。そのあとsave_dataでコミット・push
- メモの書き込みは毎回ファイルを取り直して当てて保存する。同時に保存してぶつかった（409）ら1回だけ取り直す

## 端末内（localStorage）
- `opnote_pat_token`（無ければ`diary_pat_token`）、`opnote_my_name`、`opnote_cache_content`／`opnote_cache_sha`（圏外で見るため。圏外ではメモを書かない）、`opnote_last`（前回の分類・項目）

## キャッシュバスティング
`index.html`と`js/app.js`（import文含む）の`?v=N`を同じ値で更新する。
