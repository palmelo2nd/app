# Typing（フリック入力タイムアタック）

スマホ向けのタイピング練習。お題を10問、できるだけ速く打ち切る。

## 遊び方
- レベルを選ぶ（1:ひらがな短文 / 2:ひらがな長文 / 3:漢字かな交じり）。10問がランダム（重複なし）で出る
- 最初の入力でタイム開始
- **判定は「確定したとき」だけ**行う。変換中（入力中の下線付きの状態）は判定しない
- 確定した文字列が答えと完全一致したら次の問題へ。答えの先頭部分なら入力を続け、食い違えばミス1回（打ち直すまで進めない）
- ミスは回数を表示するだけ（タイムには加算しない）。文字ごとに緑（一致）／赤（食い違い）で色分け

## 記録
- 端末内（localStorage `typing_records`）のみ。レベルごとにベストと直近20件の履歴。GitHub（`app_data/typing`）は現状使わない

## お題
- `js/modules/problems.js` の `PROBLEMS`（各レベル30問、句読点なし）。追加・差し替えはこの配列を編集
- レベル3は表記が一つに決まる言い回しだけにしている（完全一致判定のため）

## 画面上部バー
- brain等と同じ。「保存」はトークンの保存のみ（indexからの引き継ぎ用）

## キャッシュバスティング
`index.html`と`js/app.js`（import文含む）の`?v=N`を同じ値で更新する。
