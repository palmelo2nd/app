# Typing（フリック入力タイムアタック）

スマホ向けのタイピング練習。お題（レベルにより5〜15問）を、できるだけ速く打ち切る。

## 遊び方
- レベル一覧（5列×20行のマス、全100レベル。未作成は「準備中」）からマスを押し、下から出るパネルの「挑戦する」で始める（前のレベルでAランク以上を取ると次が開く）。各レベル固定の語（10語か15語。文のレベルは5文）が、毎回ランダムな順番で出る
- 最初の入力でタイム開始
- **判定は「確定したとき」だけ**行う。変換中（入力中の下線付きの状態）は判定しない
- 確定した文字列が答えと完全一致したら次の問題へ。答えの先頭部分なら入力を続け、食い違えばミス1回（打ち直すまで進めない）
- ミスは回数を表示するだけ（タイムには加算しない）。文字ごとに緑（一致）／赤（食い違い）で色分け

## タブ（遊ぶ／解説）
- **遊ぶ**：レベル一覧・プレイ・記録（下記）
- **解説**：文字の打ち方の説明（高齢の方向けに大きな文字・やさしい言葉）。定義は `js/modules/guides.js` の `GUIDES`（id・題名・対象レベル・`openAtLevel`・本文HTML）。`openAtLevel` のレベルが開くと読める（1＝最初から）。新しく開いたら結果画面でお知らせし、未読は「NEW」。読まなくてもプレイには影響しない
- 実機（iPhone）のキーボードの画面写しは `img/` に置く：`kb_kana.jpg`（かな）、`kb_kana_num.jpg`（かな側の数字・記号）、`kb_kana_abc.jpg`（かな側の英字）、`kb_qwerty.jpg`／`kb_qwerty_num.jpg`（ローマ字・英字キーボード）
- 記号のレベル用メモ（`kb_kana_num.jpg`より）：1＝☆♪→、2＝¥$€、3＝%°#、4＝○＊・、5＝＋×÷、6＝<=>、7＝「」:、8＝〒々〆、9＝^|\、0＝〜…、左下＝()[]、右下＝.,-/。※は記号キーに無いので変換（「こめ」→※）
- キーボードの図は `kb()`、1キーの十字（タップ＝まん中、左上右下＝すべらせた先）は `cross()` で作る。図の文字キーを押すと十字が出る
- 新しい文字・操作が出るレベル（Lv11濁音、Lv14半濁音、Lv29句読点、Lv32カタカナ、Lv35長音、Lv38漢字、Lv41同じ読みの漢字、Lv49数字、Lv52半角と全角…）の前に、解説ページを1つずつ追加する

## プレイ名
- 日記と同じく、登録済みの名前をボタンで選ぶ。新しい人は「＋新しい人」で登録（この端末の一覧 `typing_player_names` と、共有記録に出てくる名前を表示）
- 端末内の記録（自己ベスト・履歴）は名前ごとに保存（`typing_records:<名前>`）。v22までの `typing_records` は最初に読み込んだときの名前へ1回だけ引き継ぐ

## ランク・記録・共有
- **レベル一覧の表示**：「自分の記録」（自分の最高記録）と「みんなのベスト」（全員の中の最高記録）を切り替えられる。マスはランクで色分け（SSS＝虹色・SS＝金・S＝銀は光が流れる、A＝朱、B＝オレンジ、C＝緑、D＝青、E＝淡いグレー、未挑戦＝点線、未解放＝濃いグレーと鍵）。マスのパネルでは、そのレベルの自分の履歴とみんなのランキングを切り替えて見られる
- **自分の最高記録**：この端末の自己ベストと、共有記録の自分のプレイ名の記録のうち速い方（別の端末で遊んだ記録もレベル解放に使われる）
- **ランク判定**：レベルごとの目安タイム（全問を打ち切る秒数）でSSS/SS/S/A/B/C/D/Eの8段階（1操作あたりSSS＝0.45秒・SS＝0.6秒・S＝0.8秒・A＝1.0秒・B＝1.3秒・C＝1.6秒・D＝2.0秒。超えるとE。2026-11-03見直し）。操作の回数は清音1・濁音2・半濁音3・小さい文字2・句読点「、」「。」と長音「ー」1.5（操作1回＋キーを探す時間0.5）・記号2で、1問ごとに確定（↵）の0.5を足す（`opsOf`）。数字・記号の画面切り替えはひと続きごとに2。プレイ中は「Aランクまで あと○秒」を表示。目安は `js/modules/problems.js` の `RANK_TIMES`
- **プレイ名**：開始画面で入力（端末に記憶）。複数ユーザーで共有する際の名前になる
- **共有記録**：`palmelo2nd/app_data` の `typing/records.md`（ローカル: `app_data/typing/`）。Front Matter(JSON)の `playData` に1プレイ＝1レコード（ID・プレイ名・レベル・ミリ秒・ミス・日時）。クリア時に自動で追記する（トークン必要）
- **ランキング**：共有記録からレベルごとにプレイ名ごとのベストを集計（同タイムはミスが少ない順）。他に「みんなの最新記録」を表示
- **競合・オフライン**：追記が他の人と競合（409）したら取り直して1回だけ再試行。通信できない／トークン無しのときは端末内に未送信として残し、次の「読込」で再送する
- **端末内の記録**：自己ベストと直近20件は従来どおり端末内（localStorage `typing_records`）にも保持
- **端末内の記録を消す**：開始画面の下の「この端末の記録を消す」で、自己ベスト・履歴・未送信・共有キャッシュを消す（トークン・プレイ名・共有記録は残る）

## レベルとお題
- レベル定義は `js/modules/levels.js` の `LEVEL_DEFS` に集約（レベル番号・名前・使う文字・お題）。レベルを増やすときはここへ追記する
- 構成：Lv1〜3は行ごと（あかさ／たなは／まやらわ）、Lv4〜6はLv1〜3の全文字で10語、Lv7〜10は同じ範囲で15語（ここまで濁音・小さい文字・長音なし）。Lv11〜13は濁音、Lv14〜16は半濁音、Lv17〜19は小さい「っ」、Lv20〜22は小さい「ゃゅょ」を順に足して10語ずつ（どの語にも、そのレベルで足した文字が1つ以上）。Lv23〜25はひらがなの総合で10語ずつ（どの語にも濁音・半濁音・っ・ゃゅょのうち2種類以上）。Lv26〜28はひらがなの短い文（句読点なし）で5文ずつ（Lv26＝8〜10字、Lv27＝10〜12字、Lv28＝14〜17字）。Lv29〜31は句読点「、」「。」を足した短い文（Lv29＝「。」だけ・5文、Lv30＝「、」「。」1つずつ・5文、Lv31＝16〜19字・4文）。Lv32〜34はカタカナ（ひらがなで打って変換、「ー」なし。Lv32＝2〜3字の単語、Lv33＝小さい文字を含む単語で10語ずつ、Lv34＝カタカナ＋ひらがなの短い文5文）。Lv35〜37はのばす音「ー」（わを右へ、1操作。Lv35＝「ー」1つの単語、Lv36＝「ー」2つ・長めの単語で10語ずつ、Lv37＝ひらがなとまざった短い文5文）。Lv38〜40は漢字変換（同じ読みの別の漢字がほぼ無い語。Lv38＝2字、Lv39＝3字の語で10語ずつ、Lv40＝その語を使った短い文5文）。Lv41〜43は同じ読みの漢字（2つずつ組で出す。変換は3操作で計算。Lv41＝1字、Lv42＝2字の語で10語ずつ、Lv43＝送りがなのある語の短い文5文）。Lv44〜48は総合の短い文（漢字・カタカナ・ひらがな・句読点。漢字はふだん漢字で書く所は漢字、数字なし。5→4→4→4→3文で文を長くする。Lv47は2つの文）。Lv49〜51は数字（半角・全角どちらでも正解＝`anyWidth`。Lv49＝数字＋漢字1字の単語10語、Lv50＝短い文5文、Lv51＝数字が2か所ある文など4文）。Lv52〜54は数字だけで半角・全角を区別（お題の下に「半角で打つ／全角で打つ」＝`widthLabel`。半角5問・全角5問。Lv52＝1〜2けた、Lv53＝3〜4けた、Lv54＝5〜7けた）。Lv55〜57は数字を含む短い文で半角・全角を区別（1つの文の中ではどちらかにそろえる。5→4→3文、Lv57は数字が2か所）。語の長さはレベルが上がるほど少しずつ長くする
- 出題は各レベル固定の語（10語か15語、文は5文。お題の個数がそのまま問題数）。語は毎回同じで、出る順番だけ毎回ランダム（文字数の合計が同じなので、順位の比較は公平）
- 前のレベルの自己ベストがAランク以上になると次のレベルが開く（`problems.js` の `UNLOCK_RANK`）
- 目安タイム（ランク）は、お題の操作の回数の合計から自動計算（`problems.js` の `opsOf`・`SECONDS_PER_OP`。v24で文字数から変更）。レベルごとに `rank: {SSS,…,D}` で明示も可
- 例文が「使う文字」の範囲に収まっているか・お題が3・4・5・7・10・15個のどれかか・前のレベルと語が重複していないかは `node check-levels.mjs` で検査できる
- 共有記録の「レベル」は番号で保存するため、公開後にレベル番号の意味を変えないこと

実装で対応が必要な点：
- `check-levels.mjs` の `chars` による文字範囲の検査を、句読点・漢字・記号のレベルに合わせて直す（問題数の検査はv27で3・5・7・10・15問、v28で4問に対応済み）
- 目安タイムは読みで計算する：カタカナはひらがなに自動で直し（v29）、漢字のお題は `{ text, yomi }` で読みを持たせる（v31）。ひと続きのカタカナ・漢字ごとに変換の2操作を足す（レベルに `opsPerConversion` を書けば変える。Lv41〜43は3）。数字は1字1、ひと続きの数字・記号ごとに画面の切り替え2（ABC→☆123→あいう、v38で3から変更）を足す。全角数字は候補から選ぶので変換の2を足す（iPhoneは確定すると半角）
- 数字（Lv49〜51）と記号は半角・全角を同じとみなして判定し、Lv52〜57だけ区別する（数字はv34でレベルの `anyWidth: true` により対応。`problems.js` の `normalizeTyped`）
- iPhoneが文頭の英字を自動で大文字にするため、小文字のレベルの判定を工夫する
