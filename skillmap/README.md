# スキルマップ（skillmap）

「仲良くなる」をまん中に置き、そのために必要なことを枝として広げて書くマインドマップ（2026-11-18作成、brain #1700）。
2人で共有して、どちらも書き足せる。各枝の進み具合を色で見る。save向け（index_saveから開く）。

## 画面（上から）
- 上部バー：brain・diaryと同じ（読込・保存・トークン・キャッシュ更新・`vN`表示）
- マップ：まん中＝紺。枝の色は 灰＝未着手／青＝取り組み中／緑＝身についた。押すとその枝を選ぶ（オレンジの枠）。画面より広いときは横にずらして見る
- 選んでいる枝：進み具合（3つのボタン、押すとすぐ保存）、この枝の先に足す（名前を書いて「追加」）、ひとことメモ、名前、「保存」「削除」（先の枝がある枝は消せない。まん中は消せない）
- 進み具合：1段目の枝ごとに、その先を含めた色の割合と「身についた n ／ 全体」。押すとその枝を選ぶ
- 設定・使い方（閉じた状態）：自分の名前（書いた人として残る。未設定なら日記アプリの名前）、使い方

## データ
- 用途のデータリポジトリ（Indexが`app_data_repo`に書く。saveなら`palmelo2nd/save_data`）の`skillmap/map.md`。Front Matter(JSON)の`mapData`に1つの枝＝1レコード
- 枝：`ID`（中心は`root`、ほかは`n1`, `n2`…）・`親ID`・`名前`・`状態`（未着手／取り組み中／身についた。中心は空）・`メモ`・`並び順`・`更新者`・`更新日時`・`リンク`（任意。`{名前, URL}`。選んだ枝の欄に、そのアプリを開くボタンが出る。データに直接書く）
- 書き込みは毎回ファイルを取り直し、その上に1つの操作（追加・変更・削除）を当てて保存する。他の人と同時に保存してぶつかった（409）ら1回だけ取り直す
- ファイルが無ければ最初の形（中心「仲良くなる」＋1段目の4つの枝）を出し、最初に書き換えたときに作る

## 端末内（localStorage）
- `skillmap_pat_token`（無ければ`diary_pat_token`）、`skillmap_my_name`（無ければ`diary_my_name`）、`skillmap_cache_content`／`skillmap_cache_sha`（圏外で見るため。圏外では書き換えない）

## キャッシュバスティング
`index.html`と`js/app.js`（import文含む）の`?v=N`を同じ値で更新する。
